# Glow Beauty

Sistema Web para Gerenciamento de Clínicas de Estética

## Sobre o Projeto

Glow Beauty é uma aplicação web desenvolvida para auxiliar clínicas de estética na gestão de clientes, profissionais, serviços, agendamentos, estoque e controle financeiro.

O projeto foi desenvolvido como trabalho acadêmico do curso de Análise e Desenvolvimento de Sistemas.

---

## Funcionalidades

### Dashboard

* Indicadores gerenciais
* Próximos agendamentos
* Acesso rápido aos módulos

### Clientes

* Cadastro de clientes
* Histórico de informações
* Controle de status

### Profissionais

* Cadastro de profissionais
* Especialidades
* Controle de disponibilidade

### Serviços

* Cadastro de procedimentos
* Valores
* Duração dos atendimentos

### Agendamentos

* Controle de horários
* Associação entre cliente, profissional e serviço
* Status dos atendimentos

### Financeiro

* Receitas
* Despesas
* Lucro
* Histórico de movimentações

### Estoque

* Controle de produtos
* Quantidade disponível
* Alertas de estoque

### Usuários

* Controle de acesso ao sistema

---

## Tecnologias Utilizadas

* Next.js
* React
* TypeScript
* Tailwind CSS
* PostgreSQL (modelagem planejada)
